# PlayGif 1.0.5 — release note

**Tag:** `1.0.5`
**Title:** `PlayGif 1.0.5 — Performance: lighter on Playnite's interface`
**Asset:** `PlayGif-1_0_5.pext`

---

## GitHub release body

### Performance
- PlayGif no longer does work on every layout pass in Playnite, so other extensions, theme animations and library scrolling are no longer slowed down by it
- Media downloads and store fetches run in the background, and large videos stream to disk

### Improved
- Scrolling over a description feels the same as the rest of the page, and scrolling up no longer gets stuck. The description is now display-only (links can't be clicked)

### Known issue
- The description may move slightly out of sync with the page while scrolling. Keeping it perfectly in sync would bring back the performance issues this release removes

**Full changelog:** https://github.com/aHuddini/PlayGif/blob/main/CHANGELOG.md

---

## Short version (Discord / Reddit comment)

**PlayGif 1.0.5** is out — a performance release.

PlayGif was doing a little work every time anything in Playnite laid itself out, which slowed other extensions and themes down. It now only works when the description itself changes, and downloads and store fetches run in the background. Scrolling over a description also feels natural now.

**Known issue:** the description may move slightly out of sync with the page while scrolling. Keeping it perfectly in sync would bring back the performance issues this release removes.

Download: https://github.com/aHuddini/PlayGif/releases/tag/1.0.5

## Cutting the release

```bash
cd /c/Projects/PlayGif

# 1. merge to main
git checkout main && git merge --no-ff dev -m "Merge dev: release 1.0.5" && git push origin main

# 2. rebuild so the asset matches main
dotnet clean -c Release && dotnet build -c Release
powershell -ExecutionPolicy Bypass -File scripts/package_extension.ps1

# 3. name the asset to match installer.yaml's PackageUrl
cp "pext/PlayGif.2e196d25-24d1-4db3-b732-9766c994a496_1_0_5.pext" pext/PlayGif-1_0_5.pext

# 4. cut the release
sed -n '/^## GitHub release body$/,/^---$/p' docs/release_notes/1.0.5.md \
  | sed '1d;$d' > /tmp/pg-notes.md

gh release create 1.0.5 pext/PlayGif-1_0_5.pext \
  --target main \
  --title "PlayGif 1.0.5 — Performance: lighter on Playnite's interface" \
  --notes-file /tmp/pg-notes.md

# 5. bring dev level with main
git checkout dev && git merge --ff-only main && git push origin dev
```

## Notes

- The display-only description and natural scrolling were confirmed in a real session on Harmony. The trailing-while-scrolling known issue was observed there too; it predates this release and only became noticeable once scrolling was smooth.
- `WebView2CompositionControl` (available in the referenced SDK, 1.0.3124.44) would remove the trailing, but it copies every rendered frame into a WPF surface on the UI thread. Not adopted: it reintroduces per-frame UI work for constantly animating content.
