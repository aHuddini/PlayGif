# PlayGif 1.0.4 — release note

**Tag:** `1.0.4`
**Title:** `PlayGif 1.0.4 — Steam videos fixed, your own descriptions respected, and a description editor`
**Asset:** `PlayGif-1_0_4.pext`

---

## GitHub release body

Fixes blank Steam videos (#5), stops PlayGif overriding descriptions you or other extensions wrote (#3), fixes Preview description (#6), and adds the description editor from 1.0.3, which was not released on its own.

### Fixed
- **Steam videos play for every game** ([#5](https://github.com/aHuddini/PlayGif/issues/5)). Steam offers each description video as both MP4 and WebM. For most games the MP4 is H.264, which PlayGif prefers because your GPU decodes it cheaply. For some games, including Cyberpunk 2077, Valheim, Dead by Daylight and Trine, Steam's MP4 is HEVC instead, and the renderer cannot decode HEVC even with Windows' HEVC extension installed. Those videos stayed blank. PlayGif now detects HEVC and uses the WebM for those games, converted to MP4 when FFmpeg is set up.
- **Your own description wins** ([#3](https://github.com/aHuddini/PlayGif/issues/3)). Once PlayGif had fetched a store description, it kept showing that copy even after you, or an extension like Metadata AI, changed the description. The newer description now shows. **Fetch**, **Edit** and **Reset description** put PlayGif back in charge of a game.
- **Fetching descriptions for many games at once no longer crashes Playnite.** Every request used to start at once, with a message box for each result. It now runs one game at a time behind a progress bar you can cancel, and finishes with one summary.
- **Preview description works for every game** ([#6](https://github.com/aHuddini/PlayGif/issues/6)), including names with a `:` or `?`.
- **Media added from web search no longer shows as an empty gap.** The format is read from the download instead of guessed from the address. Imgur `.gifv` links work too.
- **Playnite no longer stays dimmed** after closing a PlayGif dialog.
- **Fullscreen mode no longer blanks the theme's description area.**
- Switching games quickly no longer shows the previous game's description. Links that open in a new tab go to your browser. Cancelling settings really discards your changes. The theme font size applies in every language. The editor can't save an empty description by mistake.

### Added
- **Edit description** (right-click a game → PlayGif → Edit description). A visual editor where your GIFs and videos play while you edit. Insert media at the cursor from web search, a URL or a file; click any media to resize or remove it; format text with headings, quotes, colour, alignment and lists; or edit raw HTML.
- **Keep your own descriptions** (Settings → General). Turn off *Replace descriptions that have no media with the store description* and PlayGif only fills in games whose description is empty ([#3](https://github.com/aHuddini/PlayGif/issues/3)).
- **Video previews in web search.** MP4 and WebM results play in the picker before you add them.

### Improved
- **Smoother scrolling.** Only videos on screen play. Previously every video in a description played at once, even scrolled out of view.
- **"Refresh description" is now "Reset description"**, and asks before discarding cached media and edits.
- Scripts embedded in description text are removed before display.

### Known issues
Theme compatibility remains the rough edge. PlayGif injects its renderer into whatever description panel your theme builds, and themes vary. Fullscreen support is still experimental. The **Known Issues** tab in settings covers this, and **Theme Support** generates a layout report for bug reports.

### Install
Download `PlayGif-1_0_4.pext` and open it with Playnite, or Add-ons → Extensions → Add extension.

**PlayGif 1.0.4** is out.

## Cutting the release

`main` carried a commit `dev` did not (the sponsors chore), so this release merges rather than fast-forwards.

```bash
cd /c/Projects/PlayGif

# 1. merge to main
git checkout main && git merge --no-ff dev -m "Merge dev: release 1.0.4" && git push origin main

# 2. rebuild so the asset matches main
dotnet clean -c Release && dotnet build -c Release
powershell -ExecutionPolicy Bypass -File scripts/package_extension.ps1

# 3. name the asset to match installer.yaml's PackageUrl
cp "pext/PlayGif.2e196d25-24d1-4db3-b732-9766c994a496_1_0_4.pext" pext/PlayGif-1_0_4.pext

# 4. cut the release
sed -n '/^## GitHub release body$/,/^---$/p' docs/release_notes/1.0.4.md \
  | sed '1d;$d' > /tmp/pg-notes.md

gh release create 1.0.4 pext/PlayGif-1_0_4.pext \
  --target main \
  --title "PlayGif 1.0.4 — Steam videos fixed, your own descriptions respected, and a description editor" \
  --notes-file /tmp/pg-notes.md
```

## Notes

- The #5 diagnosis was measured, not inferred. A WebView2 host using the renderer's exact flags decoded VP9 and H.264 with hardware acceleration, and failed HEVC with `PIPELINE_ERROR_DECODE` on a machine with the HEVC extension and an Intel Arc GPU. The MP4 codec varies per game: the owner's cache holds about 350 Steam H.264 MP4s, and those games still serve H.264.
- 1.0.3 was never published, so its installer.yaml entry was folded into this one rather than left pointing at a missing asset.
- Not verifiable outside a real session: the visible-only playback, and fullscreen injection on themes that wrap the description in a Grid.
