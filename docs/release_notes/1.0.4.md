## GitHub release body

Includes everything from 1.0.3, which was not released on its own.

### Fixed
- Steam videos play for every game, including Cyberpunk 2077 and Valheim ([#5](https://github.com/aHuddini/PlayGif/issues/5))
- Descriptions you or another extension change are no longer replaced by a cached store copy ([#3](https://github.com/aHuddini/PlayGif/issues/3))
- Preview description works for names with a `:` ([#6](https://github.com/aHuddini/PlayGif/issues/6))
- Fetching descriptions for many games at once no longer crashes Playnite
- Media added from web search no longer shows as an empty gap
- Playnite no longer stays dimmed after closing a PlayGif dialog
- Fullscreen mode no longer blanks the theme's description area

### New
- **Edit description**: a visual editor where media plays while you edit
- Setting to keep your own descriptions instead of the store's (Settings → General)
- Video previews in web search

### Improved
- Only videos on screen play, for smoother scrolling

**Full changelog:** https://github.com/aHuddini/PlayGif/blob/main/CHANGELOG.md

## Short version (Discord / Reddit comment)

**PlayGif 1.0.4** is out.

**Fixed:** blank Steam videos on games like Cyberpunk 2077 and Valheim. Steam encodes some games' MP4s as HEVC, which the renderer can't decode, so PlayGif now switches to the WebM for those. Also fixed: your own descriptions (or Metadata AI's) being replaced by a cached Steam copy, Fetch description crashing Playnite when run on a big selection, and Preview description failing on names with a `:`.

**New:** an **Edit description** visual editor (right-click → PlayGif), a setting to keep descriptions that aren't from the store, and video previews when searching for media.

**Smoother:** only videos on screen play now.

Download: https://github.com/aHuddini/PlayGif/releases/tag/1.0.4

## Cutting the release

`main` carried a commit `dev` did not (the sponsors chore), so this release merges rather than fast-forwards.

```bash
cd /c/Projects/PlayGif

# 1. merge to main
git checkout main && git merge --no-ff dev -m "Merge dev: release 1.0.4" && git push origin main

# 2. rebuild so the asset matches main
dotnet clean -c Release && dotnet build -c Release
powershell -ExecutionPolicy Bypass -File scripts/package_extension.ps1

# 3. name the asset to match installer.yaml's PackageUrl
cp "pext/PlayGif.2e196d25-24d1-4db3-b732-9766c994a496_1_0_4.pext" pext/PlayGif-1_0_4.pext

# 4. cut the release
sed -n '/^## GitHub release body$/,/^---$/p' docs/release_notes/1.0.4.md \
  | sed '1d;$d' > /tmp/pg-notes.md

gh release create 1.0.4 pext/PlayGif-1_0_4.pext \
  --target main \
  --title "PlayGif 1.0.4 — Steam videos fixed, your own descriptions respected, and a description editor" \
  --notes-file /tmp/pg-notes.md
```

## Notes

- The #5 diagnosis was measured, not inferred. A WebView2 host using the renderer's exact flags decoded VP9 and H.264 with hardware acceleration, and failed HEVC with `PIPELINE_ERROR_DECODE` on a machine with the HEVC extension and an Intel Arc GPU. The MP4 codec varies per game: the owner's cache holds about 350 Steam H.264 MP4s, and those games still serve H.264.
- 1.0.3 was never published, so its installer.yaml entry was folded into this one rather than left pointing at a missing asset.
- Not verifiable outside a real session: the visible-only playback, and fullscreen injection on themes that wrap the description in a Grid.
