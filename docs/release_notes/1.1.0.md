# PlayGif 1.1.0 — release note

**Tag:** `1.1.0`
**Title:** `PlayGif 1.1.0 — Fullscreen support and theme-placed descriptions`
**Asset:** `PlayGif-1_1_0.pext`

---

## GitHub release body

### Fullscreen
- Descriptions fit their panel at any screen resolution: sized to match the theme, no spilling over the UI, and no cut-off endings
- Descriptions are found in themes that build their pages as they open, such as Aniki ReMake, and no longer show blank there
- Descriptions are ready the first time a game's details open, and appear once the theme's slide-in finishes
- Videos resume when you reopen a game's details

### Fixed
- Converting cached media to MP4 no longer puts transparent GIFs on white boxes
- Clips are no longer stretched past their real size in wide panels

### New
- Themes can place the description renderer themselves with `PlayGif_AnimatedDescription`. See the [Theme Integration Guide](https://github.com/aHuddini/PlayGif/blob/main/docs/THEME_INTEGRATION.md)

**Full changelog:** https://github.com/aHuddini/PlayGif/blob/main/CHANGELOG.md

---

## Short version (Discord / Reddit comment)

**PlayGif 1.1.0** is out, with Fullscreen support.

Animated descriptions now work properly in Fullscreen themes. They're sized to match the theme at any resolution, they're found in themes that build their pages on demand (like Aniki ReMake), and they're ready the first time you open a game. Theme authors can also place the renderer themselves and style around it. There's a new [Theme Integration Guide](https://github.com/aHuddini/PlayGif/blob/main/docs/THEME_INTEGRATION.md).

Download: https://github.com/aHuddini/PlayGif/releases/tag/1.1.0

## Cutting the release

```bash
cd /c/Projects/PlayGif

# 1. merge to main
git checkout main && git merge --no-ff dev -m "Merge dev: release 1.1.0" && git push origin main

# 2. rebuild so the asset matches main
dotnet clean -c Release && dotnet build -c Release
powershell -ExecutionPolicy Bypass -File scripts/package_extension.ps1

# 3. name the asset to match installer.yaml's PackageUrl
cp "pext/PlayGif.2e196d25-24d1-4db3-b732-9766c994a496_1_1_0.pext" pext/PlayGif-1_1_0.pext

# 4. cut the release
sed -n '/^## GitHub release body$/,/^---$/p' docs/release_notes/1.1.0.md \
  | sed '1d;$d' > /tmp/pg-notes.md

gh release create 1.1.0 pext/PlayGif-1_1_0.pext \
  --target main \
  --title "PlayGif 1.1.0 — Fullscreen support and theme-placed descriptions" \
  --notes-file /tmp/pg-notes.md

# 5. bring dev level with main
git checkout dev && git merge --ff-only main && git push origin dev
```

Then verify the manifests. The installer check fails until the release exists:


## Notes

- Fullscreen was confirmed in a real session on Aniki ReMake at 2880x1800 / 200% (a 0.83 layout scale): the description renders, fits, scrolls and sits in the right place.
- Not yet confirmed in a real session: the Fullscreen warm-up (renderer parked before the description exists) and the `PlayGif_AnimatedDescription` slot.
- Files converted to MP4 by earlier versions keep their white backgrounds until the game's description is reset. A library-wide repair would have to re-download every GIF-origin file to check it, and was not built.
- The background-art caching experiment (`BitmapCache` on `PART_ImageBackground`) was dropped. It didn't remove the stutter over Harmony's blurred background art.
