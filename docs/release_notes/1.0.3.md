# PlayGif 1.0.3 — release note

**Tag:** `1.0.3`
**Title:** `PlayGif 1.0.3 — a description editor, and a fix for media added from the web`
**Asset:** `PlayGif-1_0_3.pext`

---

## GitHub release body

Adds a visual description editor, and fixes animated images added from web search rendering as empty gaps.

### Added
- **Edit description** (right-click a game → PlayGif → Edit description). A visual editor where your media plays while you edit it, because it renders through the same engine as the description itself.
  - **Insert at the cursor** from web image search, a direct URL, or a local file
  - Headings, quotes, text colour, alignment, lists, dividers, and clear formatting
  - Click any image or video to scale it to 25/50/75/100% or remove it
  - A raw HTML view for precise control

### Fixed
- **Animated images added from web search showed as an empty gap.** The file extension was guessed from the URL and defaulted to `.mp4` when the address had none — which is common on image CDNs. A GIF was then saved as an MP4 and wrapped in a video element the browser could not decode. The format now comes from the download itself: the file's own signature first, then the server's content type, and only then the address.
- **Imgur `.gifv` links produced nothing.** `.gifv` is not a format; the URL returns a web page wrapping an MP4. PlayGif now fetches the MP4 directly, and a link that turns out to be a page is reported rather than saved as broken media.
- **Playnite stayed dimmed after closing a PlayGif dialog**, as though a window were still open, until another dialog was opened and closed. Themes dim the main window while it owns a child window, and that state was not being refreshed when our dialogs closed.

### Changed
- **"Refresh description" is now "Reset description."** It discards the cached description and every cached media file, including media you added and any editor changes — so it is named accordingly and asks first.
- Web search results show the file format on each thumbnail, highlighted when the format is animated.
- **Add media** lists Search web images first, then From URL, then Local file.

### Known issues
Theme compatibility remains the rough edge. Playnite has no official support for animated descriptions, so PlayGif injects its renderer into whatever description panel your theme builds — themes vary, and other extensions modify the same panel. The **Known Issues** tab in settings covers this, and **Theme Support** generates a layout report for bug reports.

### Install
Download `PlayGif-1_0_3.pext` and open it with Playnite, or Add-ons → Extensions → Add extension.

**Note on the editor:** edits are saved to PlayGif's cached description, which is what gets displayed. "Reset description" discards them, and warns before doing so.

**Full changelog:** https://github.com/aHuddini/PlayGif/blob/main/CHANGELOG.md

## Notes

- The empty-gap bug was reproduced against realistic URL shapes before fixing, and verified with live downloads: a GIF served from an extensionless path is now detected from its signature.
- The dimming bug took three attempts. The first two treated it as a GPU or teardown fault; it was actually a `HasChildWindow` binding that Playnite only re-evaluates when told to. Those earlier changes were kept — sharing one WebView2 environment and not opening dialogs from inside the message callback are both correct — but neither was the cause.
- Editor edits live in the cached description only, by design. "Reset description" discards them and now warns first.
- Still unverified from earlier releases: **FusionX** theme support, and the **issue #2** startup fix, which remains marked a fix attempt until a reporter confirms it.
